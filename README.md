# 🤖 AI Study Buddy

**AI Study Buddy** is an AI-powered learning assistant designed to help students study smarter, understand concepts easily, and generate personalized learning content using Artificial Intelligence.

The project uses **Google Gemini Models** to provide intelligent and personalized responses based on the student's learning requirements.

## 🚀 Features

* 🤖 AI-powered study assistance
* 📚 Personalized learning support
* 🧠 AI-generated explanations for difficult concepts
* 📝 Study content generation
* 💡 Intelligent suggestions and learning guidance
* 🎯 Personalized study planning
* 📊 Structured database schema and models
* 🖥️ Simple and user-friendly interface
* ⚡ Powered by Google Gemini AI

## 🛠️ Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python
* **AI Model:** Google Gemini
* **Database:** SQL / Relational Database
* **Development Environment:** Visual Studio Code
* **Version Control:** Git & GitHub

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/murugavelv352-crypto/Ai-Study-Buddy.git
```

### 2. Open the Project

```bash
cd Ai-Study-Buddy
```

Open the project folder in **Visual Studio Code**.

### 3. Install Required Dependencies

Install the required Python packages using:

```bash
pip install -r requirements.txt
```

> If a `requirements.txt` file is not available, install the dependencies mentioned in the project source code.

### 4. Configure Gemini API

Create a Gemini API key and add it to your environment configuration.

Example:

```env
GEMINI_API_KEY=your_api_key_here
```

**Never upload your API key or other secrets to GitHub.**

### 5. Run the Application

Run the project's main Python file:

```bash
python app.py
```

> Replace `app.py` with the actual entry-point file if your project uses a different filename.
